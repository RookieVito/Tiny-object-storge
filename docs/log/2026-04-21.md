# 开发日志

## 2026-04-21

### Bug 修复

1. **Web UI 签名查询参数泄漏**
   - 问题：`s3Request` 将完整 path（含 `?delimiter=/&max-keys=1000`）传给 `signV2` 计算签名，但服务器 `auth.go` 构造 canonicalResource 时不含查询参数，导致 ListObjects 请求返回 403
   - 修复：`web/src/api/client.ts` 签名前用 `path.split('?')[0]` 剥离查询参数
   - 文件：`web/src/api/client.ts`

2. **ListObjects XML 根元素名缺失**
   - 问题：`listBucketResult` 结构体缺少 `XMLName` 字段，Go `xml.Encoder` 输出的根元素名为 `listBucketResult`（小写），前端 `querySelector('ListBucketResult')` 匹配失败
   - 修复：添加 `XMLName xml.Name \`xml:"ListBucketResult"\``
   - 文件：`src/handler/bucket.go`

3. **下载请求未携带认证头**
   - 问题：`downloadUrl` 只拼裸 URL，通过 `<a href>` 下载不带 `Authorization` 头，GET 对象返回 403
   - 修复：新增 `downloadObject` 函数，带签名 GET 请求获取 Blob 后触发浏览器下载
   - 文件：`web/src/api/client.ts`、`web/src/components/ObjectBrowser.tsx`

4. **Bucket 创建输入框字符重影**
   - 问题：绝对定位的 `BUCKET://` 装饰文字与输入框内容重叠
   - 修复：移除装饰文字，简化为纯输入框
   - 文件：`web/src/components/BucketList.tsx`

### 性能优化

1. **Auth Context 不必要的重渲染**
   - 问题：`AuthProvider` 每次渲染创建新 context value，导致消费 `useAuth` 的组件被不必要重渲染，触发重复 API 请求
   - 修复：`login`/`logout` 用 `useCallback`，context value 用 `useMemo`；组件中用 `useRef` 持有 config 引用，从 `loadObjects`/`loadBuckets` 依赖中移除 config
   - 文件：`web/src/hooks/useAuth.tsx`、`web/src/components/ObjectBrowser.tsx`、`web/src/components/BucketList.tsx`

2. **移除 React.StrictMode**
   - 问题：开发模式下 StrictMode 双倍渲染和双倍执行 effects
   - 修复：移除 `main.tsx` 中的 `<React.StrictMode>` 包裹
   - 文件：`web/src/main.tsx`

### 功能实现

1. **EC 存储自修复（Self-Healing）**
   - 背景：删除某个磁盘上的分片后，GetObject 能通过 RS 解码恢复数据，但缺失分片不会写回，随时间推移分片丢失越多最终无法恢复
   - 实现：`GetObject` 中检测缺失分片，RS 解码后自动将缺失分片写回原磁盘，修复失败不影响本次读取
   - 文件：`src/storage/ec.go`

2. **Web UI 赛博朋克视觉重设计**
   - 视觉风格：深色背景 + 霓虹色系（cyan/magenta/purple）+ mesh 渐变 + CRT 扫描线 + glassmorphism 卡片
   - 字体：Orbitron（标题）、Rajdhani（UI）、JetBrains Mono（技术数据）
   - 动画：页面切换 slide-up/fade-in、列表项交错入场、加载进度条渐变发光
   - 新增拖拽上传：支持将文件拖拽到 ObjectBrowser 页面任意位置上传
   - 文件：`web/src/styles/index.css`、`web/tailwind.config.js`、`web/index.html`、所有组件文件
